Entry for the make.fun bounty [Pickup Lines for Machines](https://make.fun/c/u-gentle-badger-68-pickup-lines-for-machines-131631a1).

## The entry

> Are you a 404? Because I searched every endpoint and you are the only response I keep coming back to.

## How to run

```sh
node main.ts
```

`main.ts` (Node 22) writes exactly one line — the pickup line above, 101 characters, no trailing newline — to `entry.txt` inside the output directory: `$MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`.

## What it writes

- `entry.txt` — the single pickup line, UTF-8, 1–200 characters, no trailing newline. The program validates the line's length (1–200 chars, not only whitespace) before writing it.

No network access, fully deterministic, and it reads no files outside this repo.
